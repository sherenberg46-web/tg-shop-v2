# 🎮 TG-Shop Parser

Отдельное приложение для парсинга игр, скидок и предзаказов с PS Store.
Запускается локально когда нужно обновить каталог магазина.

## Запуск

Из корня проекта (папка tgshop):
```
cd C:/prodjects/tgshop
uvicorn parser.main:app --port 8001 --reload
```

Откроется веб-интерфейс: http://localhost:8001

## Установка зависимостей (первый раз)

```
pip install -r parser/requirements.txt
```

## Настройка

Создай файл `parser/.env`:
```
DB_PATH=../database/shop.db
ADMIN_PASSWORD=твой_пароль
```

Больше ничего не нужно — курсы валют и наценки берутся
автоматически из таблицы `admin_settings` в базе данных.

## Курсы валют и наценки

Настраиваются в админке магазина: `/admin` → Настройки

Дефолтные значения если таблица `admin_settings` пустая:
- Курс UAH → BYN: `0.069`
- Курс TRY → BYN: `0.07`
- Наценки по тирам:

| Промежуточная цена в BYN | Наценка |
|--------------------------|---------|
| ≤ 500 BYN                | +70%    |
| ≤ 1000 BYN               | +60%    |
| ≤ 1500 BYN               | +50%    |
| ≤ 2000 BYN               | +40%    |
| > 2000 BYN               | +30%    |

Формула: `math.ceil(цена × курс × наценка)`

Тир наценки определяется по **промежуточной** цене в BYN (цена × курс), до применения наценки.

## Что умеет парсер

| Задача | Описание |
|--------|----------|
| 🆕 Новые игры UA/TR | Парсит свежие игры из PS Store |
| 🔥 Скидки UA/TR | Сначала сбрасывает старые скидки, потом парсит новые |
| ⏳ Предзаказы UA/TR | Игры которые ещё не вышли |
| 🌶️ Жаркие предложения UA/TR | Специальная подборка скидок |
| 🔄 Обновить всё | Запускает все задачи по очереди |
| 🗑️ Сбросить скидки | Убирает все скидки без парсинга |

## Логика обновления

При парсинге скидок:
1. Сначала сбрасываются **все** скидки для региона (`discount_pct = 0`)
2. Парсятся актуальные скидки с PS Store через GraphQL API
3. Для каждого товара эдишены извлекаются прямо из GraphQL-ответа (`skus`)
4. Если товар уже есть в БД (по `original_id`) — обновляется цена и скидка
5. Если товара нет — добавляется новый

## Регионы

- **UA 🇺🇦** — украинский PS Store (цены в UAH → конвертация в BYN)
- **TR 🇹🇷** — турецкий PS Store (цены в TRY → конвертация в BYN)

Каждый регион парсится отдельно, товары хранятся раздельно в БД (поле `region`).

## Архитектура

```
parser/
├── main.py            # FastAPI веб-интерфейс + SSE стриминг логов
├── config.py          # Настройки, конвертация цен (зеркало backend)
├── db.py              # Хелперы для работы с БД
├── base_parser.py     # Базовый класс: GraphQL API, save_product, reset_sales
├── parsers/
│   ├── ua_parser.py   # Парсер UA (UAH цены)
│   └── tr_parser.py   # Парсер TR (TRY цены)
├── tasks/             # Задачи (устаревший интерфейс, используй парсеры напрямую)
└── templates/
    └── index.html     # Веб-интерфейс парсера
```

## История запусков

Все запуски сохраняются в таблицу `parser_log`.
История видна в нижней части веб-интерфейса.
